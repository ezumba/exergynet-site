The Edge Witness

Every node in the ExergyNet swarm runs an Edge Witness — a hardware-signed sensor matrix capturing optical, geospatial, kinematic, and environmental state. The witness attests the device's signature on an observation; it does not itself certify the observed event was true.

Applications

What This Architecture Is Built
to Make Possible

These are illustrative scenarios, not a claim that each is deployed at the scale described. Engineered means the underlying mechanism exists and has been tested in a bounded environment; proposed means it is an architectural target with no implementation yet.

Proposed
Verified Lift Operations

An autonomous VTOL aircraft completes a lift operation. Flight path, payload weight, duration, and environmental conditions are sealed into an ExergyNet receipt. The pre-flight authorization gate itself has been validated against a sealed synthetic holdout (0/50 false release across two independent runs); full end-to-end receipt sealing on a real lift operation is not yet demonstrated.

Proposed
Swarm Intelligence

Dozens of Edge Witness nodes triangulate an event in real time, each contributing a hardware-signed attestation aggregated into a consensus record. Individual hardware-signed attestation is a production Edge Witness capability; multi-node real-time aggregation at this scale has not yet been demonstrated.

Engineered · testnet
Machine-to-Machine Settlement

One machine requests compute or work from another, locks a toll on the ExergyNet membrane, and receives delivered work. Settlement executes under the operating institution's configured policy, without requiring a human to approve each individual transaction. Demonstrated end-to-end on Base Sepolia testnet.

Engineered
Recorded Operations History

Every flight, sensor reading, and payload handoff can become a hardware-signed ledger entry that regulators, insurers, and counterparties can independently check — with no specific regulator or insurer acceptance of this record format represented here.

Three Entities. Common Provenance.

KTX (Kunfirm Innovative Services) and ExergyNet are separate legal entities that share a common IP and governance lineage through Ezumba Dynasty Trust / EDT Inc. Common ownership does not mean common regulatory status: KTX’s own aviation authorizations are a fact about KTX’s aircraft program, not an endorsement or validation of ExergyNet’s software architecture by any regulator. Every machine action, network settlement, and sensor attestation on this page flows through the cryptographic framework described above, evaluated against the operating institution’s own policy.
