AI Agent Memory
Tools Compared

"Agent memory" covers several different kinds of product — a memory layer, a temporal knowledge graph, a stateful agent framework, an SDK, and a memory-plus-authority control plane. They are not interchangeable. This is an honest map of where mem0, Zep, Letta, LangMem, and ExergyNet each fit.

First, The Categories

Five tools, not one category

Before comparing features, it helps to see that these tools answer different questions. Some manage what an agent remembers; one is a framework you build the whole agent inside; ExergyNet governs memory and the authority to act on it.

Side By Side

The landscape at a glance

ToolWhat it isRetrieval basisResult verifiabilityAuthority control
mem0 Open-source memory layer (managed option) LLM-extracted "salient" memories; optional graph Not a stated feature Out of scope
Zep / Graphiti Temporal knowledge-graph memory (Graphiti OSS; Zep enterprise) Bi-temporal graph + hybrid semantic/text search Fact validity intervals; not content-hash Out of scope
Letta (MemGPT) Open-source stateful agent framework OS-inspired tiers; agent self-manages via tools Not a stated feature Out of scope
LangMem LangChain SDK for long-term memory LLM extraction of semantic memories; backend-agnostic Not a stated feature Out of scope
ExergyNet Memory + authority control plane Deterministic, content-addressed SHA-256 content hash on each result Separate deterministic authority layer

"Out of scope" is not a criticism — mem0, Zep, Letta, and LangMem are memory tools and do not claim to be authorization layers. It marks a difference in what the product is for, so you can combine them correctly rather than expect one to do the other's job.

Where ExergyNet Fits

Memory you can verify, and act on safely

ExergyNet is the option to reach for when the memory drives consequences: retrieval is deterministic and content-addressed (the same query over the same committed state returns the same, hash-checkable bytes), the evidence window stays bounded as the store grows, and the authority to act on that evidence is a separate, deterministic decision — not the model's. Several of these tools can even sit alongside it; ExergyNet is the control plane, not another store.
