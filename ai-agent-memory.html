Persistent Memory

AI Agent
Memory

Autonomous agents need memory that outlives a single session and a single prompt. ExergyNet gives agents durable, content-verified long-term memory that persists across runs, machines, and time — without stuffing an ever-growing history into the context window.

The Problem

A context window is not memory

The most common way to give an agent "memory" is to paste its history back into the prompt on every turn. This breaks down as the agent accumulates state: the context window has a hard ceiling, prefill cost rises with every token you re-send, and older evidence gets truncated or silently dropped. Bigger context windows postpone the wall; they do not remove it. Memory that lives only inside the active prompt is memory you pay for, in full, on every single request.

The deeper issue is a conflation: an agent's accumulated state (everything it has ever learned or done) and its active context (what the model needs for the query in front of it) are treated as the same resource. They are not.

What Real Agent Memory Requires

Four properties

Durable

State survives across sessions, process restarts, and machine boundaries — not just within one conversation.

Bounded at inference

What reaches the model per query stays small and relevant, even as the underlying corpus grows large.

Verifiable

Retrieved evidence is content-addressed — the same query over the same committed state returns the same bytes, checkable by hash.

Portable

Memory is not welded to one model. Swap the reasoning engine; the persistent substrate stays.

How ExergyNet Does It

Externalize the state, bound the evidence

ExergyNet keeps the agent's accumulated state outside the inference request. For each query it retrieves a bounded, content-verified evidence window from that state and hands only that window to the model. The persistent corpus can keep growing; what the model reads per query stays bounded by what retrieval selects — not by how much the agent has accumulated.

  • Store Root-addressed, content-verified persistent evidence (Exergy Vault / xLMP)
  • Retrieve Deterministic, content-addressed — no probabilistic similarity guesswork in the path
  • Deliver A bounded evidence window to the model, independent of corpus size
  • Verify SHA-256 content hash on every memory-query result

For the measured scaling behavior behind this design — how active model-facing context holds bounded as the corpus grows — see the Benchmarks & Evidence page.
