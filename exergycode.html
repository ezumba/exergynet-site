Every AI session starts from zero.
Yours doesn't have to.

Traditional AI coding tools are stateless. When a session ends, the work disappears. You rebuild context from scratch. Your models forget what your team already established.

Projects accumulate decisions, architectural constraints, and completed tasks. None of that should live exclusively in a chat window.

ExergyCode connects to ExergyNet's persistent memory infrastructure. Engineering decisions, task completions, and verified checkpoints are preserved and selectively retrieved when needed — not replayed in full every time.

Each session starts with what's relevant. Each session ends with a verifiable record of what was done.

Resource accounting

Know what you've spent.
Control what you spend next.

ExergyNet introduces RHO — a normalized resource accounting unit that attributes computational work to the tasks that created it.

ExergyCode surfaces this measurement in your terminal so you can make informed decisions about session scope, model selection, and task boundaries.

RHO is a measurement, not a price. It is not a cryptocurrency, stablecoin, or redeemable asset.

Persistent state

Memory that grows with your project.
Context that stays bounded.

ExergyCode stores engineering knowledge in your personal VMN namespace — a local-first, hash-linked memory vault powered by ExergyNet's persistent state infrastructure.

When you start a new session, ExergyCode retrieves what's relevant. When you finish, it records what was verified.

Each session starts better than the last, without replaying everything that came before it.

Authority layer

Agents under authority.
Not running loose.

ExergyCode sessions operate under a permission structure you define. This is not a soft guardrail.

01 / STRUCTURE

Permission structure

Elevated commands require explicit authorization. Agents cannot exceed the scope of what they have been permitted to do.

02 / EVIDENCE

Evidence-bound checkpoints

Verified task completions produce Ed25519-signed checkpoints — a durable, inspectable record of what was done and what evidence supported it.

03 / BOUNDARY

Hard execution boundary

The authority layer operates independently of the model. Execution decisions are not delegated to the inference provider.
