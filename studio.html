Product definition

Not a new runtime.
A better view of the same one.

ExergyNet Studio does not replace ExergyCode. It runs on the same ExergyNet authority layer, the same VMN namespace, and the same persistent state infrastructure.

Studio adds a graphical surface to work already in progress. Visual diffs, checkpoint inspection, multi-agent approval flows — the operations that benefit from a broader view than a single terminal.

One account. One memory namespace. Two interfaces.

Architecture

Adapter architecture.

Studio's provider adapter layer connects your existing inference account to the ExergyNet authority layer.

A1

Provider adapter

Routes inference requests to your authorized provider account. Provider keys stay in your environment.

A2

Memory adapter

Connects Studio sessions to your VMN namespace. Retrieval and storage stay consistent with ExergyCode sessions.

A3

Authority adapter

Routes execution proposals to the ExergyNet authority layer. Decisions are independent of the inference provider.

A4

Telemetry adapter

Records session events, resource consumption (RHO), and checkpoint state. Local-first; remote sync requires API key.
