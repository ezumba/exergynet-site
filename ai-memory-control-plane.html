Control Plane

A memory library stores bytes. A memory control plane governs them — deciding what an agent can retrieve, whether that evidence is verifiable, and whether the agent is authorized to act on it. ExergyNet is that control plane: the system around the model, not another store bolted onto it.

The Idea

What is a memory control plane?

Borrowed from networking, a "control plane" is the layer that decides how things move, separate from the layer that moves them. Applied to agent memory, it is the governance layer between an autonomous agent and its accumulated state: it decides what evidence reaches the model, guarantees that evidence is what it claims to be, and keeps the authority to act on that evidence separate from the reasoning that proposes the action. Most "agent memory" today is just a store. A control plane is what you need once an agent's memory drives consequences.

The Core Separation

Integrity ≠ Provenance ≠ Authority

The reason a control plane matters is that three questions people collapse into "memory" are actually different, and each needs its own guarantee:

Integrity

Is this evidence intact and unaltered? Answered by content addressing — every result carries a SHA-256 hash you can check.

Provenance

Where did it come from, and is it the currently authoritative version? Answered by version-aware, deterministic resolution over committed state.

Authority

May the agent act on it? Answered by a separate, deterministic authority layer — never by the reasoning model itself.

Conflating these is how agents end up trusting stale specs, acting on tampered evidence, or authorizing their own consequences. Keeping them separate is the whole point of a control plane.

What It Governs

Store, retrieve, verify, authorize

  • Store Persistent state held outside the inference request — durable across sessions, models, and machines
  • Retrieve A bounded, deterministic evidence window per query — small regardless of how large the store grows
  • Verify Content-addressed results, checkable by hash — integrity and provenance, not best-effort recall
  • Authorize A separate, deterministic decision on whether the agent may act — independent of the model's judgment
